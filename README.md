# explaining-ai

Apresentação (deck HTML) e kit prático para explicar **o que é IA de verdade** a arquitetas: LLM, token, janela de contexto, inferência, harness (rules, skills, hooks, MCP), agentes e orquestração, licenciado × open source e como configurar o Codex.

Visual no estilo da apresentação do TCC (papel claro, teal, divisores escuros, Inter + JetBrains Mono embutidas). Linguagem direta, inspirada nas palestras do Fabio Akita.

## Abrir e apresentar
Abra `index.html` no navegador — funciona offline, sem instalar nada.

| Tecla | Ação |
|---|---|
| ← → / espaço | navegar |
| `N` | notas do apresentador (o que falar, frases literais, avisos) |
| `O` | visão geral de todos os slides |
| `F` | tela cheia |
| `P` | imprimir / salvar PDF (1 slide por página, 1920×1080) |

O palco é 1920×1080 e se ajusta ao projetor. No celular (ou em retrato) os slides se reorganizam em coluna.

São 71 slides (7 partes). Para caber em ~60 min, pule os marcados como **opcional** nas notas (mapa da IA, fabricantes, concorrentes, "no seu mundo").

## Recortes reais para capturar
Três slides têm um espaço tracejado "Captura real · substituir": prompt de aprovação do Codex, gerenciador de layers do CAD e a planilha `levantamento.xlsx`. Veja as regras de captura em `codex-kit/README.md`. Todas as outras telas do deck são **recriações ilustrativas** marcadas "exemplo fictício".
