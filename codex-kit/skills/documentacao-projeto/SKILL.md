# Documentação de projeto

## Entradas
Tópicos/briefing, lista de ambientes e acabamentos, memorial anterior como modelo (`entrada/modelo-memorial.md`).

## Passos
1. Siga a estrutura do modelo do escritório; se não houver, proponha uma e peça aprovação.
2. Redija por ambiente/sistema, linguagem técnica clara, sem adjetivos vazios.
3. Onde faltar dado (marca, referência, espessura), escreva `[PREENCHER: ...]` — nunca invente.
4. Normas: cite só número e ano que você tenha certeza; senão `[CONFERIR NORMA]`.
5. Gere `saida/memorial.md` e `saida/pendencias-documento.md` (todos os `[PREENCHER]`).
6. Revisão cruzada: compare áreas, nomes de ambientes e acabamentos entre memorial e lista de ambientes; liste divergências.

## Regras
- Texto é rascunho técnico: a arquiteta responsável revisa e assina.
